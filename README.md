Mental Health & Emotional Support Platform for Children

> **Tech Stack:** MERN (MongoDB, Express.js, React.js, Node.js) + Python Flask (ML)

## Project Overview

This project is a web-based psycho-emotional monitoring and therapy platform tailored for children affected by stress and traumatic events, as well as their parents and specialists.

The platform combines interactive child-friendly activities (game therapy, fairy-tale therapy) with scientifically backed psychological assessment tests. Machine Learning models analyze test results to detect early signs of stress, anxiety, or emotional distress, allowing parents and specialists to receive data-driven insights.

---

## Key Features

- **Dual-Zone User Interface:**
  - **Child Area:** Gamified interface with interactive garden mechanics ("Garden of Feelings"), mood tracking, and fairy-tale therapy.
  - **Parent/Specialist Dashboard:** Detailed metrics, assessment history, ML-generated diagnostic reports, and recommendations.
- **Psychometric Testing Suite:**
  - Assessment modules based on established psychological frameworks (Go/No-Go, Dembo-Rubinstein scale, SUDS).
- **Machine Learning Analysis:**
  - Flask-based Python service utilizing Random Forest Classifier to process test parameters and generate risk factors.
- **Privacy & Compliance:**
  - Architected with GDPR and national child data privacy standards in mind.
